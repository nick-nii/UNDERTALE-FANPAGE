SISTEMA DE BATALHA:

* O sistema de batalha de Undertale é diferente do RPG tradicional. Durante os confrontos, o jogador não precisa necessariamente derrotar os inimigos atacando. É possível escolher diferentes ações e encontrar maneiras alternativas de resolver cada batalha. Durante o combate, o jogador possui quatro opções principais: FIGHT, ACT, ITEM e MERCY. A opção FIGHT permite atacar o inimigo. ACT permite realizar ações específicas, como conversar, provocar ou interagir com o monstro. ITEM permite utilizar objetos encontrados durante a aventura, enquanto MERCY permite poupar o inimigo quando determinadas condições são cumpridas.


* Quando o inimigo ataca, o coração que representa a alma de Frisk aparece dentro de uma área de batalha. O jogador precisa movimentá-lo e desviar dos ataques, como projéteis, obstáculos e padrões diferentes. Por isso, o sistema mistura elementos de RPG com desafios de habilidade e reflexo.


* Cada monstro possui comportamentos e padrões de ataque próprios. Além disso, algumas ações realizadas durante a batalha podem alterar a forma como o inimigo reage, permitindo que o jogador descubra maneiras de encerrá-la sem violência.


* As decisões tomadas durante os combates também podem influenciar a história. Atacar, poupar ou agir de determinadas maneiras contribui para o caminho seguido pelo jogador e pode afetar acontecimentos posteriores. Assim, o sistema de batalha de Undertale transforma os confrontos em mais do que simples lutas. Cada batalha é uma oportunidade de escolher como você quer tratar seus adversários e quais consequências está disposto a enfrentar.
